# FretFoundry

FretFoundry is a single-page beginner guitar learning app. It includes guided lessons, visual chord diagrams, a daily practice plan, a metronome, a two-minute practice timer, progress tracking, and a quick quiz.

## Run locally

Open the `prismacolor2` HTML file directly in a browser, or serve it with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/prismacolor2`.
