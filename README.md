# Tiny Piano Teacher

A single-page interactive piano learning app for beginners. Pick from 10 simple songs, listen to a demo, then follow highlighted notes on the on-screen keyboard to practice the melody.

## Features

- 10 beginner-friendly songs, including Twinkle Twinkle, Mary Had a Little Lamb, Ode to Joy, and Happy Birthday.
- Interactive piano keys with Web Audio tones.
- Guided lesson mode that highlights the next note and tracks score/streak.
- Adjustable demo tempo from 50 to 140 BPM.
- Computer keyboard shortcuts for quick practice.

## Usage

Open `prismacolor2` in a web browser.
